## 📖 Overview

This repository contains my solutions to the assignments for the **Image Processing** course. Each folder covers a distinct topic.

The goal isn't just to get correct output, but to actually understand *why* each technique works: what's happening to the pixel data, why a kernel is shaped the way it is, and where each method breaks down.

## 🧩 What's Inside

- 📁 One folder per assignment, each self-contained with its own code and sample outputs
